# موقع IO

موقع بسيط لعرض أكوادك وألعابك. يشتغل على **GitHub Pages** مجاناً بدون أي تثبيت.

## إزاي ترفعه على GitHub (من المتصفح، بدون برامج)

1. افتح github.com وسجّل دخول، واضغط **New repository** (علامة + فوق).
2. اكتب اسم للمشروع، مثلاً `io-site`، واخترها **Public**، واضغط **Create repository**.
3. في صفحة المشروع اضغط **uploading an existing file**.
4. فك ضغط الملف المضغوط على جهازك، وسحب **كل الملفات والمجلدات اللي جواه** (index.html و style.css و app.js و config.js ومجلد projects) وارميها في الصفحة.
5. انزل تحت واضغط **Commit changes**.
6. روح **Settings** ثم **Pages**. في **Branch** اختار `main` وبعدها `/ (root)` واضغط **Save**.
7. استنى دقيقة أو اتنين، وهيظهر لك رابط الموقع فوق في نفس الصفحة، شكله:
   `https://اسم-حسابك.github.io/io-site/`

## إزاي تغيّر الاسم أو النصوص
افتح ملف `config.js` وغيّر `name` و `tagline` و `about`. ولو كتبت اسم حسابك في `github` هيظهر زر GitHub في الصفحة.

## إزاي تضيف مشروع جديد
1. حط ملف الـ HTML بتاعك جوه مجلد `projects`.
2. في `config.js` انسخ واحد من الأسطر اللي جوه `projects` وغيّر `file` و `title` و `desc`.
